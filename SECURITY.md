# Security Policy

The Vocdoni team takes the security of our software and services seriously. We appreciate the efforts of security researchers and users who responsibly disclose potential vulnerabilities.

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in a Vocdoni project, **please do not report it through a public GitHub issue, discussion, or pull request**.

Instead, use GitHub's **Private Vulnerability Reporting** feature in the affected repository:

1. Open the affected Vocdoni repository on GitHub.
2. Go to **Security → Advisories**.
3. Select **Report a vulnerability**.
4. Provide as much information as possible about the vulnerability.

When reporting a vulnerability, please include, where applicable:

- A description of the vulnerability.
- The affected component or repository.
- Steps to reproduce the issue.
- The potential security impact.
- A proof of concept or example demonstrating the issue.
- Any suggested remediation or mitigation.

Please avoid including sensitive vulnerability information in public GitHub issues, discussions, pull requests, or other public channels.

## Disclosure Process

The Vocdoni team will review submitted security reports and assess their impact and severity.

We may contact the reporter through the private GitHub Security Advisory to request additional information, coordinate remediation, or discuss disclosure.

We ask reporters to allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

Once a vulnerability has been addressed, Vocdoni may publish a GitHub Security Advisory describing the issue, its impact, affected versions, and available fixes or mitigations.

## Scope

This policy applies to software maintained by the Vocdoni GitHub organization.

Individual repositories may define additional or more specific security policies. When a repository contains its own `SECURITY.md`, that policy takes precedence over this organization-wide policy.

## Safe Harbor

Vocdoni supports good-faith security research intended to identify and responsibly disclose vulnerabilities.

We ask researchers to avoid:

- Accessing, modifying, or deleting data that does not belong to them.
- Disrupting or degrading Vocdoni services or infrastructure.
- Performing denial-of-service attacks.
- Using discovered vulnerabilities beyond what is necessary to demonstrate their existence and impact.
- Publicly disclosing vulnerabilities before Vocdoni has had a reasonable opportunity to investigate and remediate them.

We will make reasonable efforts to work constructively with researchers who follow this policy and report vulnerabilities in good faith.
