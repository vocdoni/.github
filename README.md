# Vocdoni

**Secure, private and universally verifiable digital voting.**

Vocdoni develops open-source technology for secure digital voting and governance. Our goal is to make voting accessible to organizations while providing strong guarantees of privacy, integrity, transparency and verifiability.

Our technology is designed for organizations of all sizes, including associations, cooperatives, professional organizations, unions, companies, municipalities and other institutions that need to conduct secure digital voting.

## Vocdoni App

[Vocdoni App](https://app.vocdoni.io) is our ready-to-use digital voting platform.

It provides organizations with the tools required to create and manage voting processes while using the Vocdoni protocol to provide verifiable voting and privacy guarantees.

Learn more at **https://vocdoni.io** or start using the application at **https://app.vocdoni.io**.

## Build with Vocdoni

Vocdoni can also be integrated into third-party applications and services.

The **Vocdoni API** provides a simple interface for managing organizations, members, censuses, voting processes and results, while our SDKs handle voter-facing operations such as ballot creation, signing and submission.

Start with the developer documentation:

**https://vocdoni.io/developers/docs/**

## Main repositories

 - [**vocdoni-app**](https://github.com/vocdoni/vocdoni-app): The Vocdoni digital voting application. It provides the user-facing platform for organizations to create and manage secure voting processes.
 - [**saas-backend**](https://github.com/vocdoni/saas-backend): Backend powering the Vocdoni SaaS platform and API.
 - [**vocdoni-node**](https://github.com/vocdoni/vocdoni-node) and [**vocdoni-sdk**](https://github.com/vocdoni/vocdoni-sdk): Core implementation of the Vocdoni voting protocol and distributed node infrastructure, written in Go, and the TypeScript SDK for interacting with the Vocdoni API and voting protocol.

## DAVINCI

Vocdoni is also developing **DAVINCI — Decentralized Autonomous Vote Integrity Network with Cryptographic Inference**, the next generation of our voting protocol.

DAVINCI combines cryptographic techniques such as zero-knowledge proofs with decentralized infrastructure to provide strong privacy, integrity and verifiability guarantees for digital voting.

Key repositories:

- [davinci-node](https://github.com/vocdoni/davinci-node) — DAVINCI node and sequencer implementation.
- [davinci-contracts](https://github.com/vocdoni/davinci-contracts) — EVM smart contracts for the DAVINCI protocol.
- [davinci-paper](https://github.com/vocdoni/davinci-paper) — DAVINCI protocol whitepaper.
